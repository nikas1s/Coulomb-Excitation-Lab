# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, constructive and welcoming to everyone, whatever their background, level of experience or language (English or Greek are both supported in the app).

**Reporting:** unacceptable behaviour can be reported by opening a private security advisory on this repository (Security tab), or by contacting the maintainer through their GitHub profile. Reports are reviewed promptly and kept confidential.
